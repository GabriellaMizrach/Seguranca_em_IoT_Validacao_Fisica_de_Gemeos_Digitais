# Defesa-F-sica-para-G-meos-Digitais-Valida-o-de-Dados-IoT-contra-Ataques-de-Envenenamento
Sistema IoT para proteção de Gêmeos Digitais contra envenenamento de dados. Utiliza Arduino e Python para validar a integridade das leituras de sensores através da Correlação Cruzada de Leis da Física (Mecânica dos Fluidos, Termodinâmica e Conservação de Energia).
